# Décisions d'architecture (ADR)

Une décision notable, une page : le contexte, la décision, les conséquences. On ne modifie pas une décision acceptée : on la **remplace** par une nouvelle, et on met à jour son statut.

| N° | Titre | Statut |
|---|---|---|
| [0001](0001-stack-et-style-darchitecture.md) | Stack et style d'architecture | Acceptée |

## Modèle

```markdown
# ADR NNNN : titre

- Statut : proposée | acceptée | remplacée par NNNN
- Date : AAAA-MM-JJ

## Contexte
Pourquoi cette décision est nécessaire.

## Décision
Ce qui est décidé.

## Conséquences
Ce que ça apporte, ce que ça coûte, ce qu'on s'interdit.
```
